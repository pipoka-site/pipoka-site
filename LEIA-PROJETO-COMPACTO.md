# Projeto compacto para GitHub Web

Este pacote contém somente os arquivos necessários para o projeto e para as atualizações atuais do Supabase.

- Total de arquivos: menos de 100, compatível com o envio pelo navegador do GitHub.
- Envie o conteúdo extraído diretamente para a raiz do repositório.
- Não envie a pasta externa envolvendo `app`, `components`, `lib`, `public` e `supabase`.
- Os documentos históricos e SQLs antigos foram colocados em um backup separado.
